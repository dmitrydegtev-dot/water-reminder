1. Создайте репозиторий на github.com и загрузите в него всё содержимое этой папки (вместе со скрытой папкой .github).
2. Откройте вкладку Actions, дождитесь окончания сборки Build APK (2-5 минут).
3. Откройте завершённый запуск, внизу в Artifacts скачайте water-apk, распакуйте архив.
4. Перенесите app-debug.apk на телефон и установите (разрешите установку из неизвестных источников).
